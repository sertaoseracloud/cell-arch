# Phase 2 – Sidecar Proxy – Plan 03: Azure CosmosDB Client

**Goal:** Implement Azure CosmosDB client with Workload Identity authentication.

**Success Criteria**

- `internal/sidecar/azure/cosmosdb_client.go` creates a CosmosDB container client using Workload Identity (no static credentials).
- Client accepts `context.Context` in all operations.
- Unit tests mock the CosmosDB interface and achieve ≥80% coverage.

## Tasks

1. **Create Azure SDK client initialization**
   - Create `internal/sidecar/azure/cosmosdb_client.go`:

     ```go
     package azure

     import (
         "context"
         "github.com/Azure/azure-sdk-for-go/sdk/azidentity"
         "github.com/Azure/azure-sdk-for-go/sdk/data/azcosmos"
     )

     type CosmosDBClient struct {
         container *azcosmos.ContainerClient
     }

     func NewCosmosDBClient(ctx context.Context, endpoint, database, container string) (*CosmosDBClient, error) {
         cred, err := azidentity.NewDefaultAzureCredential(nil)
         if err != nil {
             return nil, fmt.Errorf("failed to get Azure credential: %w", err)
         }

         client, err := azcosmos.NewClient(endpoint, cred, nil)
         if err != nil {
             return nil, fmt.Errorf("failed to create CosmosDB client: %w", err)
         }

         db, err := client.NewDatabase(database)
         if err != nil {
             return nil, err
         }

         container, err := db.NewContainer(container)
         if err != nil {
             return nil, err
         }

         return &CosmosDBClient{container: container}, nil
     }
     ```

2. **Implement Get operation**
   - Add `Get(ctx context.Context, id string) (*Task, error)` method.
   - Use `container.ReadItem` with partition key and id.

3. **Implement Create operation**
   - Add `Create(ctx context.Context, task *Task) error` method.
   - Use `container.CreateItem`.

4. **Add unit tests**
   - Create `internal/sidecar/azure/cosmosdb_client_test.go`.
   - Mock the CosmosDB interface.
   - Test Get (success, not found, error cases).
   - Test Create (success, error cases).
   - Run `go test ./internal/sidecar/azure/... -cover` ensure ≥80%.
