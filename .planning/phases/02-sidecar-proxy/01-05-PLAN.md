# Phase 2 – Sidecar Proxy – Plan 05: Health-Check & Tests

**Goal:** Add gRPC health-check endpoint and comprehensive unit tests for the sidecar.

**Success Criteria**

- HealthCheck gRPC method verifies credential validity and basic cloud connectivity.
- All packages under `internal/sidecar/` have ≥80% test coverage.
- `go test ./...` passes for the entire sidecar.
- Health-check can be called via `grpcurl` or test client.

## Tasks

1. **Implement HealthCheck method**
   - Update `cmd/sidecar/main.go` server struct to include health status.
   - Implement `HealthCheck`:

     ```go
     func (s *server) HealthCheck(ctx context.Context, req *pb.HealthCheckRequest) (*pb.HealthCheckResponse, error) {
         // Lightweight auth check - verify clients are initialized
         if s.awsClient == nil {
             return &pb.HealthCheckResponse{Status: "UNHEALTHY", Message: "AWS client not initialized"}, nil
         }
         if s.azureClient == nil {
             return &pb.HealthCheckResponse{Status: "UNHEALTHY", Message: "Azure client not initialized"}, nil
         }

         // Optional: lightweight connectivity check (describe table for AWS, read database for Azure)
         // For performance, only do this periodically, not on every health check

         return &pb.HealthCheckResponse{Status: "SERVING", Message: "All systems operational"}, nil
     }
     ```

2. **Add integration tests for gRPC server**
   - Create `cmd/sidecar/main_test.go`:
     - Start gRPC server in test with mTLS disabled (or use insecure for testing).
     - Test HealthCheck returns SERVING.
     - Test GetTask with invalid cloud returns InvalidArgument.
     - Test CreateTask routing.

3. **Ensure ≥80% coverage for all sidecar packages**
   - Run `go test ./internal/sidecar/... -coverprofile=coverage.out`.
   - Check coverage for `internal/sidecar/aws/`, `internal/sidecar/azure/`, `internal/sidecar/selector/`, `internal/sidecar/errors/`.
   - Add missing tests if coverage <80%.

4. **Add graceful shutdown for sidecar**
   - Ensure `cmd/sidecar/main.go` has signal handling (similar to app).
   - Listen for SIGINT/SIGTERM and gracefully stop gRPC server.

## Verification Steps

- `go build ./cmd/sidecar` succeeds.
- `go test ./...` passes for sidecar packages.
- Coverage report shows ≥80% for all `internal/sidecar/` packages.
- HealthCheck can be invoked (in test) and returns SERVING.
- Graceful shutdown works (send SIGINT, verify server stops).

## Artifacts

- Updated `cmd/sidecar/main.go` with HealthCheck implementation
- `cmd/sidecar/main_test.go` with gRPC server tests
- Coverage report for sidecar packages
