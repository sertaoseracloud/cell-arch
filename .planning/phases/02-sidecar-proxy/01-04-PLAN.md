# Phase 2 – Sidecar Proxy – Plan 04: Per-Request Cloud Selector

**Goal:** Implement per-request cloud selector and gRPC methods that route to AWS or Azure based on request field.

**Success Criteria**

- gRPC server methods (`GetTask`, `CreateTask`, etc.) inspect `req.Cloud` field and route to appropriate client.
- Invalid cloud values return `codes.InvalidArgument`.
- All gRPC methods accept `context.Context` as first parameter.
- Unit tests cover routing logic and error cases.

## Tasks

1. **Create cloud selector helper**
   - Create `internal/sidecar/selector/selector.go`:

     ```go
     package selector

     import "context"

     type TaskClient interface {
         Get(ctx context.Context, id string) (interface{}, error)
         Create(ctx context.Context, task interface{}) error
     }

     func Route(ctx context.Context, cloud string, awsClient, azureClient TaskClient) (TaskClient, error) {
         switch cloud {
         case "aws":
             return awsClient, nil
         case "azure":
             return azureClient, nil
         default:
             return nil, fmt.Errorf("unsupported cloud: %s", cloud)
         }
     }
     ```

2. **Implement gRPC server with routing**
   - Update `cmd/sidecar/main.go` to include server struct with AWS and Azure clients.
   - Implement `GetTask`:

     ```go
     func (s *server) GetTask(ctx context.Context, req *pb.GetTaskRequest) (*pb.GetTaskResponse, error) {
         var client TaskClient
         switch req.Cloud {
         case "aws":
             client = s.awsClient
         case "azure":
             client = s.azureClient
         default:
             return nil, status.Errorf(codes.InvalidArgument, "unsupported cloud: %s", req.Cloud)
         }

         result, err := client.Get(ctx, req.TaskId)
         if err != nil {
             return nil, mapAWSError(err)
         }

         task, ok := result.(*pb.Task)
         if !ok {
             return nil, status.Errorf(codes.Internal, "failed to cast task")
         }

         return &pb.GetTaskResponse{Task: task}, nil
     }
     ```

3. **Map AWS/Azure errors to gRPC status codes**
   - Create `internal/sidecar/errors/mapper.go`:

     ```go
     package errors

     import (
         "fmt"
         "github.com/aws/aws-sdk-go-v2/service/dynamodb/types"
         "google.golang.org/grpc/codes"
         "google.golang.org/grpc/status"
     )

     func mapAWSError(err error) error {
         var oe *types.ResourceNotFoundException
         if fmt.ErrorAs(err, &oe) {
             return status.Errorf(codes.NotFound, "resource not found: %v", err)
         }
         return status.Errorf(codes.Internal, "internal error: %v", err)
     }
     ```

4. **Add unit tests**
   - Test routing logic with mock clients.
   - Test error mapping (NotFound → codes.NotFound, etc.).
   - Run `go test ./internal/sidecar/...` passes.

- Invalid cloud values return proper gRPC error.
