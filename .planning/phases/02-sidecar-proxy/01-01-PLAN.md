# Phase 2 – Sidecar Proxy – Plan 01: Setup gRPC Server with mTLS

**Goal:** Provide a runnable gRPC sidecar server with mTLS enabled on localhost:50051.

**Success Criteria**

- `cmd/sidecar/main.go` starts a gRPC server on `:50051` with mTLS.
- Server cert/key loaded from env vars `TLS_CERT` and `TLS_KEY`.
- Generated protobuf stubs (`task.pb.go`, `task_grpc.pb.go`) exist.
- `go build ./cmd/sidecar` succeeds.
- HealthCheck returns `SERVING` (no clients yet).

## Tasks

1. **Define protobuf service**
   - Create `proto/task.proto` with `TaskService` (GetTask, CreateTask, QueryTasks, DeleteTask, HealthCheck).
   - Include `cloud` field in requests for per-request selector.
   - Run `protoc --go_out=. --go-grpc_out=. proto/task.proto`.

2. **Implement gRPC server scaffold**
   - Create `cmd/sidecar/main.go`:
     - Load TLS cert/key from env.
     - Create `grpc.NewServer(grpc.Creds(creds))`.
     - Register `TaskServiceServer`.
     - Listen on `:50051` and serve.
   - Add graceful shutdown (context.WithCancel + signal.Notify).

3. **Add config loader**
   - Create `internal/sidecar/config/config.go` with `LoadConfig(ctx)` reading `sidecar.yaml`.
   - Struct fields: `TLSCert`, `TLSKey`, `AWSEndpoint`, `AzureEndpoint`, `Region`.

4. **Write unit tests**
   - `cmd/sidecar/main_test.go`: test that server starts and HealthCheck returns `SERVING`.
   - Use `grpc.Dial` with client TLS cert.

## Verification Steps

- `go build ./cmd/sidecar` succeeds.
- `go test ./cmd/sidecar/...` passes.
- `openssl s_client -connect localhost:50051 -cert client.crt -key client.key` succeeds (mTLS handshake).

## Artifacts

- `proto/task.proto`
- `proto/task.pb.go`, `proto/task_grpc.pb.go`
- `cmd/sidecar/main.go`
- `internal/sidecar/config/config.go`
- `cmd/sidecar/main_test.go`
