# Phase 2 – Sidecar Proxy – Plan 02: AWS DynamoDB Client

**Goal:** Implement AWS DynamoDB client with IRSA authentication.

**Success Criteria**

- `internal/sidecar/aws/dynamodb_client.go` creates a DynamoDB client using IRSA (no static credentials).
- Client accepts `context.Context` in all operations.
- Unit tests mock the DynamoDB interface and achieve ≥80% coverage.

## Tasks

1. **Create AWS SDK client initialization**
   - Create `internal/sidecar/aws/dynamodb_client.go`:

     ```go
     package aws

     import (
         "context"
         "github.com/aws/aws-sdk-go-v2/aws/config"
         "github.com/aws/aws-sdk-go-v2/service/dynamodb"
     )

     type DynamoDBClient struct {
         client *dynamodb.Client
         tableName string
     }

     func NewDynamoDBClient(ctx context.Context, region, tableName string) (*DynamoDBClient, error) {
         cfg, err := config.LoadDefaultConfig(ctx, config.WithRegion(region))
         if err != nil {
             return nil, fmt.Errorf("failed to load AWS config: %w", err)
         }
         return &DynamoDBClient{
             client: dynamodb.NewFromConfig(cfg),
             tableName: tableName,
         }, nil
     }
     ```

2. **Implement Get operation**
   - Add `Get(ctx context.Context, id string) (*Task, error)` method.
   - Use `client.GetItem` with `Key: map[string]types.AttributeValue{"id": &types.AttributeValueMemberS{Value: id}}`.
   - Map response to `Task` struct.

3. **Implement Create operation**
   - Add `Create(ctx context.Context, task *Task) error` method.
   - Use `client.PutItem` with marshaled Task.

4. **Add unit tests**
   - Create `internal/sidecar/aws/dynamodb_client_test.go`.
   - Mock the DynamoDB interface (use `github.com/stretchr/testify/mock`).
   - Test Get (success, not found, error cases).
   - Test Create (success, error cases).
   - Run `go test ./internal/sidecar/aws/... -cover` ensure ≥80%.

## Verification Steps

- `go build ./cmd/sidecar` succeeds.
- `go test ./internal/sidecar/aws/...` passes with coverage ≥80%.
- No static credentials (grep for `AWS_ACCESS_KEY` returns nothing).
