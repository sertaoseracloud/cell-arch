<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| CI → AWS/Azure | OIDC token is exchanged for temporary cloud credentials. |
| CI → Repository | Workflow reads source code; must not expose secrets. |
## STRIDE
| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-05-01 | Spoofing | OIDC token request | mitigate | Use `permissions.id-token: write` and restrict `audiences` in trust policies (per D-15). |
| T-05-02 | Tampering | Workflow yaml | mitigate | Enforce branch protection (D-13) and require status checks. |
| T-05-03 | Information Leakage | Artefact upload | mitigate | Artefacts are stored in GitHub Actions internal storage; no secret values are written. |
</threat_model>
