## STRIDE
| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|

| T-05-14 | Information Leakage | Release logs | mitigate | Mask any secret env vars (none should exist). |
</threat_model>
